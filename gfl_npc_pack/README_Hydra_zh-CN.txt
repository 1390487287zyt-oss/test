Hydra · Garry’s Mod / VJ Base

安装
请按本包 README_zh-CN.txt 安装。

动作与武器
移动时四条腿分组迈步，髋、膝和足部独立运动。上方两根副炮交替开火，下方中央是主炮。
主炮有独立的蓄力、后坐与爆炸溅射。敌人在约 300 Source 单位之外且主炮就绪时会优先使用主炮，
近距离或主炮冷却中使用副炮。AI 寻路和目标选择由 VJ Base 驱动，适合在开阔、有 AI 节点的场地进行测试。

友军
采用用户提供的 KCCO 模组所用的 CLASS_TAU，另包含 KCCO、URNC 和少女前线军方的专用阵营标签。
vj_gfl_enemies_snpcs 的 KSSO 使用 CLASS_KSSO。VJ Base 对应的 HECU 标签是 CLASS_UNITED_STATES。
采用自定义标签的其他军方模组可在 lua/entities/npc_vj_gfl_hydra/shared.lua 的 VJ_NPC_Class 表中追加对应值。

模型
安装包含 Hydra 的模型网格和全套贴图。动作由 Lua 驱动，安装包不依赖之前的 Hydra 道具版。

本次修正
副炮使用《半条命 2》三脚机甲 Strider 的闪光材质和曳光效果。安装覆盖前先退出游戏。
闪光跟随客户端实际绘制的左、右炮管位置，包括机体转向和炮管后坐。
自发光网格增加了局部深度间距，用于消除眼灯发光层和装甲之间的闪烁。

射击调整
副炮按 左×4 → 右×4 → 左×4 → 右×4 射击，共 16 发。
每发基础伤害 40，全部命中为 640。起手后 0.18 秒打出第一发，之后每隔 0.10 秒一发，
最后一发在 1.68 秒打出。含收尾后坐，两轮起手理论最短间隔为 1.86 秒。
主炮改用《半条命 2》联合军 APC 的原生口焰（ChopperMuzzleFlash），发光位置随主炮的枪口和后坐移动。

性能修正
主炮和副炮都用同一套服务端计时逻辑。受伤或 AI 更换目标时，已开始的一轮继续按时序执行。打完、关闭 AI、Hydra 死亡或移除时清理计时器。
副炮闪光主动清理过期记录，即使 Hydra 在屏幕外也会到期回收，每台最多保留 4 条待绘制记录。
主炮 APC 炮口辅助模型在口焰结束时回收。

副炮同步修正
副炮由同一个服务端计时器安排全部 16 发，第一发起手后 0.18 秒，发与发相隔 0.10 秒。
每发实际开火时通知客户端，让对应炮管的后坐、原版《半条命 2》AR2 枪声、炮口火花与曳光一起播放。
每发重新瞄准敌人的可受击位置，瞄准点受遮挡时尝试头部。墙体和友军仍会拦截射击。
更新多人服务器时，服务端和客户端都需安装本版。

移动与机身震动
沿用原版导航模型尺寸、碰撞边界和视点。有速度更低的有效行走动作时，追击也使用原生行走动作。
步态按实际地面位移推进，走过同样距离使用同样的步数。
每次对角足组落地时，底盘略微下沉，并给周围的地面玩家一次短暂震屏。
左右副炮实际开火时，机身会随对应炮管后仰、侧摆和回弹。主炮开火会产生更重的后仰和回弹。

生命值与死亡爆散
KCCO - Hydra 使用新实体类名 npc_vj_gfl_pack_hydra。VJ Base 初始化完成后以及沙盒菜单生成时，当前生命和最大生命设为 11000。
也可以在单人游戏控制台输入 gmod_spawnnpc npc_vj_gfl_pack_hydra 直接生成新版 Hydra。
在单人游戏确认时，先重新生成 Hydra，对准它后在控制台运行下面一行，查看服务端的当前生命和最大生命。
lua_run local p=player.GetHumans()[1]; if IsValid(p) then local e=p:GetEyeTrace().Entity; if IsValid(e) then print(e:GetClass(), e:Health(), e:GetMaxHealth()) end end
新生成、未受伤的 Hydra 预期输出 npc_vj_gfl_pack_hydra 11000 11000。
死亡后机身下沉，底盘和炮塔相继爆开。主副炮、装甲和四足关节共 18 个部件飞散、翻滚并落地。
残骸是客户端视觉效果，约 14 秒后清理。大量 Hydra 同时死亡时，每个客户端最多保留四组残骸。

索敌距离与低矮装甲瞄准
默认视距为 5000 游戏单位。敌人可见且超出 3650 单位射程时，Hydra 会在有可用路线时接近。
敌人在 175～3650 单位内且可见时，通常停下瞄准射击。处于遮挡后方的敌人使用 VJ Base 的原生寻路逻辑。
主副炮对低矮目标和载具优先瞄准实体碰撞边界内的车体位置。首选瞄点受阻时，会尝试可命中的其他位置。
识别为 VJ Base 坦克炮手的目标会转而瞄准其底盘。子弹仍按实际射线处理，墙体和友军可拦截。
