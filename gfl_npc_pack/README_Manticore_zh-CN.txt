蝎甲兽 Manticore · VJ Base SNPC

安装
请按本包 README_zh-CN.txt 安装。

阵营
使用现有铁血模组的 CLASS_SANGVIS 与 CLASS_AUT，以及 vj_gfl_enemies_snpcs 的 CLASS_SF 标签。VJ Base 通过共同标签建立友军关系。

基础参数
基础生命 6000，视距 3600，视角 165°。默认难度和 NPC 生命值设置可由 VJ Base 全局选项覆盖。
主炮单发 96 点直击伤害，附带 112 单位半径的爆炸，边缘伤害递减，爆心溅射上限 44。
每次起手约 0.32 秒后开炮，连续可用时起手间隔约 2.7 秒。
有效射程约 190～2400 游戏单位。发现敌人且超出射程时会尝试接近，有视线且进入射程时通常停下开火。
主炮会瞄准低矮装甲车体。墙体与友军可拦截射击。

模型与动作
PMX 模型约 324 × 116 × 199 游戏单位，按其原有关节驱动四足、前腿液压杆及单门主炮。
步态按实际地面位移推进，落脚会震屏。主炮带俯仰、后坐及机身回弹，死亡时分件爆散。
使用客户端网格呈现 PMX 外观及动作。服务器的导航和碰撞由 VJ Base 驱动。
蝎甲兽和九头蛇由同一个合包提供，原铁血模组可作为友军单位同时使用。
